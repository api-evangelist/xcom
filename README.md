# XCOM

XCOM (XCOM Technologies Inc.) was a competitive local exchange carrier (CLEC) based in Cambridge, Massachusetts, backed by Battery Ventures and Matrix Partners. Level 3 Communications acquired the company in April 1998 in a stock-for-stock deal valued at roughly $165 million. The company is defunct as an independent entity and publishes no website, developer portal, or API surface — the xcom.com domain now belongs to the unrelated 2K Games XCOM video game franchise.
